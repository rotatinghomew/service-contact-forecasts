# 资料字典

本地时间用北京时间，自 8、11、14、17 时起各有一个三小时服务时段，晚间最后结束。转交驻留时两站可同时承担工作负荷，旅客的等待只记一次。转交超过 replay_windows 记录的容许认领时间时，再收到回执不能按已及时接收归责。已离队不是无需求，延后登记的回拨只在资料可见后用于校准。首次进线要去重，转接可能形成技能负荷但不形成下一条独立需求。区域服务水平和站点服务水平必须按相同一组需求与服务任务判断。

## `coverage.json`

渠道在时段内可观察到初次接洽的范围。

| 字段 | 含义 |
| --- | --- |
| `window` | 初次接洽窗口 |
| `day` | 服务日 |
| `site` | 来源点位 |
| `slot` | 四个服务时段，从 0 开始 |
| `day_type` | 公告日型 |
| `covered` | 登记是否完整 |
| `estimated_rate` | 估计登记覆盖率，可空 |
| `known` | 覆盖记录可见日 |

## `contacts.json`

咨询链的转接纪录和晚到的结局。

| 字段 | 含义 |
| --- | --- |
| `event` | 事件标识 |
| `thread` | 同一个咨询事务 |
| `window` | 首次进线窗口 |
| `site` | 发生位置或远程接受站 |
| `skill` | 实际需要的语言技能 |
| `kind` | 业务事件种类 |
| `at` | 本地日内分钟，空为暂缺 |
| `duration` | 实际服务分钟，空为未知 |
| `known` | 该事件当时可见日 |

## `handoff_ack.json`

尝试转交与收方实际认领有不同的事件和可见时间。

| 字段 | 含义 |
| --- | --- |
| `thread` | 咨询链 |
| `origin` | 请托站点 |
| `destination` | 接收站点 |
| `offered` | 尝试转交的日内分钟 |
| `accepted` | 实际认领日内分钟，可空 |
| `known` | 记录可见日 |
| `state` | 认领进度及更正 |

## `replay_windows.json`

值班室在这些可比运行日复盘，并登记最迟认领和翌日回拨的边界。

| 字段 | 含义 |
| --- | --- |
| `day` | 对照运行日 |
| `last_reply` | 当日最晚答复分钟 |
| `accept_minutes` | 尝试转交后最长认领时间分钟 |
| `candidate` | 是否可参与试切换 |

## `teams.json`

同一人同一日同一窗口只可使用一次。

| 字段 | 含义 |
| --- | --- |
| `member` | 人员号 |
| `day` | 可上班日 |
| `home` | 主站 |
| `slot` | 服务时段 |
| `skills` | 可承接技能 |
| `minutes` | 该班可用于服务的分钟 |
| `lend` | 是否可作为联营能力 |

## `dispatch_calendar.json`

业务方已知的后续集散情况和变化范围。

| 字段 | 含义 |
| --- | --- |
| `day` | 日历日期 |
| `day_type` | 预先公布的日型 |
| `condition` | 可能改变到达的上下文 |
| `announced` | 已知日 |

## `guarantees.json`

留有本地和区域服务水平，等待阈值按首次进线分钟起算。

| 字段 | 含义 |
| --- | --- |
| `site` | 站点或区域 |
| `skill` | 服务语言 |
| `slot` | 时段 |
| `wait_cap` | 允许等待分钟 |
| `coverage` | 等待上限以内的最小服务比例 |

## `booked_loans.json`

已接受及被关闭的实际借班动作。

| 字段 | 含义 |
| --- | --- |
| `loan` | 借用号 |
| `member` | 被借成员 |
| `day` | 使用日 |
| `slot` | 服务时段 |
| `recipient` | 承接咨询站点 |
| `state` | 业务状态 |
| `known` | 首次通知日 |
